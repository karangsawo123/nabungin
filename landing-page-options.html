Dibangun untuk transparansi nyata

Semua yang dibutuhkan untuk menabung bersama

Multi-Workspace

Satu akun untuk tabungan pribadi sekaligus beberapa grup kolaboratif. Pisahkan pos "Dana Darurat" dari "Liburan Bali" tanpa perlu ganti akun.

Target Finansial dengan Deadline

Buat goal dengan nama, nominal target, dan tanggal tenggat. Progress bar otomatis menghitung persentase berdasarkan saldo riil dari database, bukan input manual.

Pos Kategori Transaksi

Setiap setoran dan penarikan diberi label pos: Alokasi Bulanan, Bonus dan THR, Sisa Belanja, atau kategori custom yang Anda buat sendiri per workspace.

Notifikasi Realtime

Saat anggota lain menyetor atau goal mencapai 100%, lonceng notifikasi di navbar menyala secara langsung tanpa me-refresh halaman berkat Supabase Realtime.

Proteksi Anti-Minus

Trigger PostgreSQL menjaga agar saldo tidak pernah negatif. Penarikan melebihi saldo tersedia langsung ditolak di level database, bukan hanya validasi UI.

Ekspor Laporan CSV

Unduh seluruh riwayat mutasi per workspace dalam format CSV atau Excel. Cocok untuk rekonsiliasi akhir bulan atau pembukuan bersama kelompok.

Perubahan nyata

Dari cara lama yang rawan, ke catatan yang transparan dan akurat

Sebelum Nabungin
Dana tabungan tercampur dengan uang belanja harian di satu rekening.
Tidak ada catatan siapa setor berapa. Konfirmasi lewat screenshot di grup chat yang cepat tenggelam.
Progress target tidak terlihat jelas karena saldo dihitung manual atau dikira-kira.
Penarikan berlebih tidak terdeteksi sampai saldo sudah habis dan target gagal.
Dengan Nabungin
Setiap tujuan punya pos sendiri. Dana Darurat, Liburan, DP Rumah, semuanya terpisah dan tidak bisa terpakai tidak sengaja.
Setiap setoran tercatat siapa, kapan, dan berapa. Anggota bisa lihat riwayat lengkap kapan saja.
Progress bar dihitung langsung dari database, bukan input manual, sehingga persentase selalu akurat.
Trigger database menolak penarikan melebihi saldo. Saldo tidak bisa minus, target tetap aman.
Integritas Data

Saldo dihitung database, bukan klien

Tidak seperti spreadsheet, Nabungin menghitung saldo langsung dari jumlah transaksi di PostgreSQL. Tidak ada celah manipulasi manual dari sisi UI.

Row Level Security di Supabase: data antar workspace tidak bisa bocor satu sama lain.
Trigger otomatis: setiap mutasi langsung menyinkronkan saldo goal tanpa input manual.
Invite token berbatas waktu: link undangan punya tenggat dan kuota, tidak bisa disalahgunakan.
Pencapaian tersimpan permanen: setelah goal lunas, status achieved tidak hilang meski ada penarikan berikutnya.
Alur Transaksi
1
Isi form transaksi dengan nominal, goal, dan kategori, lalu simpan.
2
Server Action Next.js memvalidasi data dengan Zod sebelum masuk ke database.
3
Trigger PostgreSQL otomatis menghitung ulang saldo goal dari SUM semua transaksi.
4
Jika target tercapai, notifikasi dikirim ke seluruh anggota workspace via Supabase Realtime.

Ekosistem fitur

Semua komponen dalam satu platform

Workspace Management 01

Personal dan Shared Workspace dalam satu akun

Setiap pengguna mendapat Personal Workspace otomatis saat mendaftar. Buat Shared Workspace baru kapan saja untuk proyek tabungan bersama, lalu undang anggota lewat link token berbatas waktu dan kuota.

Personal Workspace (default) Shared Workspace Invite Token berbatas waktu Role: Owner / Member
Target Finansial02

Goal dengan Progress Bar Dinamis

Buat target dengan nama, nominal, tenggat, ikon, dan warna. Progress bar dihitung dari SUM transaksi riil. Status otomatis berubah ke "achieved" ketika saldo menyentuh target.

active / achieved / cancelledDeadline tracking
Ledger Mutasi03

Deposit dan Penarikan Terklasifikasi

Setiap transaksi wajib terhubung ke satu Goal dan satu Kategori. Catatan tanggal dan notes bisa ditambahkan. Pemilik transaksi atau owner grup bisa mengedit atau menghapus.

Deposit / WithdrawalKategori customFilter tanggal
Integritas Database04

Saldo Auto-Kalkulasi via Trigger

Trigger PostgreSQL menghitung ulang saldo goal setiap kali ada INSERT, UPDATE, atau DELETE transaksi. Tidak ada saldo yang bisa diubah langsung dari sisi klien.

Anti-minus (BR-009)Milestone persistence
Realtime05

Notifikasi Lonceng Tanpa Refresh

Supabase Realtime WebSocket mengirim event ke semua anggota workspace saat ada transaksi baru atau goal tercapai. Badge lonceng bertambah secara instan.

Supabase RealtimeIn-app bell badge
Audit Trail06

Activity Log Transparan

Setiap aksi di workspace dicatat di activity_logs: siapa, apa, kapan. Feed timeline bisa diakses seluruh anggota. Histori tetap ada meski akun pembuat dihapus.

Ledger auditSoft delete user
Laporan dan Ekspor

Unduh Riwayat Transaksi ke CSV atau Excel

Seluruh mutasi per workspace dapat diekspor dalam format spreadsheet standar. Cocok untuk rekonsiliasi akhir bulan, laporan bersama, atau arsip keuangan pribadi.
